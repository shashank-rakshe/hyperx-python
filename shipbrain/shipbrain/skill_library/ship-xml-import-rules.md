# Importing a ship structure XML into an FE surface model

Goal: natural connections (all edges connected) WITHOUT moving the real position of frames, decks and webs. The XML draws each part to the FACE of the part it butts into, so a raw import leaves gaps equal to a plate thickness.
Fixed references: web, frame and deck positions. Everything else (flanges, faceplates, brackets) aligns to them. Not changed: member dimensions, snipes, notches, corner arcs, part names; the Offset tag is ignored.
Order per panel: pre-scan all parts, boundary limits, move the whole panel if needed, build plates and close thickness gaps, stiffeners, faceplates and brackets, write a report of every gap and rule that fired.
- **Rule 1 - Boundary Limits.** When: A plate Boundary <Limit> references another part through ModelRef (Plate, Stiffener, Faceplate, Surface). Does: The plate edge moves onto the referenced part. - **Rule 3 - Web onto frame.** When: A stiffener web lies parallel to another panel plane on its material side, exactly its own web thickness away (+/-0.5 mm). Does: The web moves onto that plane, and its flange moves with it. Brackets attached to the web follow (Rule 11).
